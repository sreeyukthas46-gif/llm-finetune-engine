# LLM Finetune Engine

A comprehensive framework for fine-tuning large language models with support for multiple architectures and training strategies.

## Project Structure

- **src/** - Source code for the fine-tuning engine
- **data/** - Data storage and preprocessing
- **configs/** - Configuration files for training
- **tests/** - Unit and integration tests
- **scripts/** - Utility scripts for various tasks

## Getting Started

1. Install dependencies: `pip install -r requirements.txt`
2. Configure training parameters in `configs/`
3. Run fine-tuning scripts from `scripts/`

## Requirements

See `requirements.txt` for all dependencies.
